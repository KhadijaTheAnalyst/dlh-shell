# dlh-shell

Linux shell scripting projects completed as part of the **AI Academy at Digital Learning Hub Luxembourg**, following the Holberton School ML Engineering curriculum.

## Overview

This repository focuses on Linux shell scripting and file system permissions — essential skills for working in server environments, automating tasks, and managing ML infrastructure.

## Topics Covered

- **File Permissions** — `chmod`, `chown`, `chgrp` and understanding permission bits (rwx)
- **Symbolic Links** — Creating and managing hard and soft links
- **File Search** — Using `find` with filters for name, type, permissions, and ownership
- **Ownership Management** — Changing user and group ownership of files and directories
- **Shell Scripts** — Writing and executing Bash scripts for task automation
- **Special Permission Bits** — setuid, setgid, and sticky bit

## Tools & Environment

- **Shell:** Bash (Linux / WSL)
- **OS:** Ubuntu (via WSL on Windows)
- **Version Control:** Git & GitHub

## Structure

Each script is a standalone solution to a specific permission or shell task from the curriculum. Scripts are numbered and named to reflect their exercise in sequence.
